# Captions Pop — legenda palavra a palavra (estilo cortes de podcast / talking head)

**Quando usar:** cortes de podcast, vídeos com pessoa falando, b-roll narrado, tutoriais rápidos. A legenda É o motion.
**Referências do gênero:** cortes de podcast virais, criadores "business/educação" com legenda amarela palavra a palavra.

| Item | Valor |
|---|---|
| Fonte | Montserrat 900, CAIXA ALTA, contorno preto 14 px + sombra |
| Legenda | 1–3 palavras por vez, palavra falada fica amarela (#ffe600), palavras-chave verdes (#36ff6b) com pop + SFX |
| Posição | centro-baixo (y≈1080–1250), dentro da safe zone |
| Fundo | vídeo do usuário (cena `image` com `src` .mp4/.jpg) ou gradiente animado |
| Títulos de cena | opcionais, no topo (use `show` curto ou vazio) |
| Transições | punch/whip discretos; corte seco na maior parte |

Ative com `"captions": {"enabled": true, "emph": ["dinheiro", "grátis"]}` no data.json.
