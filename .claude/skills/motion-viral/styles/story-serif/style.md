# Story Serif — storytelling / documentário / curiosidades históricas

**Quando usar:** histórias reais, "a história de como…", true crime leve, curiosidades históricas, biografias de marcas.
**Referências do gênero:** mini-documentários verticais, canais de storytelling com tipografia editorial.

| Item | Valor |
|---|---|
| Fontes | DM Serif Display (títulos, minúsculas) + Inter (apoio) |
| Paleta | fundo #14100c, creme #f6efe4, laranja #ff7a1a, pêssego #ffd29a |
| Entrada | rise com máscara (palavra sobe de dentro da linha) |
| Destaque | marcador laranja varrendo a palavra |
| Transições | zoom suave e whip; sem flash |
| Textura | grão forte (10%), vinheta, gradiente quente se movendo |
