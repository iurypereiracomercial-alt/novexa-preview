# Kinetic Impact — tipografia pesada batendo no ritmo da voz (faceless viral)

**Quando usar:** curiosidades, dicas, "X erros que…", listas, estatísticas, motivacional, vídeos faceless com narração.
**Referências do gênero:** canais faceless de curiosidades/finanças/produtividade; edições "kinetic typography" de shorts.

| Item | Valor |
|---|---|
| Fontes | Anton (títulos, CAIXA ALTA) + Montserrat 800 (apoio) |
| Paleta | fundo #0a0a0c, texto #fff, destaque #ffd60a (box), secundário #ff3b5c |
| Entrada | hook=slam, text=pop, list=rise (máscara), quote=blur, cta=slam |
| Saída | zoom (escala 1.5 + blur, 0.22 s) |
| Transições | punch no gancho (1º quadro sempre legível); depois ciclo punch → whip → shake → punch → glitch |
| Destaque | caixa amarela atrás da palavra + pop + micro-shake |
| Movimento contínuo | zoom lento 5% por cena (tela nunca parada) |
| SFX | whoosh nas transições, pop nos destaques, impact nos golpes, riser em estatísticas |
| Textura | grão de filme 8% + vinheta + barra de progresso no topo |

Ritmo ideal: 1 ideia por cena, 3–7 palavras por cena, cenas de 1,2–2,5 s.
